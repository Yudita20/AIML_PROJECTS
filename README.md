## Projects

### 1. Customer Churn Prediction

**Tech Stack:** Python, PyTorch, Scikit-learn, Pandas, NumPy, Streamlit

An Artificial Neural Network (ANN)-based application that predicts the likelihood of customer churn using customer demographics, service usage, and billing information.

**Key Implementations:**
- Data preprocessing and feature engineering.
- ANN architecture using PyTorch.
- Dropout regularization and early stopping.
- Model evaluation using accuracy, precision, recall, F1-score, and ROC-AUC.
- Interactive prediction interface using Streamlit.

### 2. Transformer Architecture from Scratch

**Tech Stack:** Python, PyTorch

A from-scratch implementation of the Transformer architecture for a language translation task, based on the research paper *Attention Is All You Need*.

**Key Implementations:**
- Input Embeddings and Sinusoidal Positional Encoding.
- Scaled Dot-Product Attention.
- Multi-Head Self-Attention.
- Masked Self-Attention.
- Cross-Attention.
- Feed-Forward Networks.
- Residual Connections and Layer Normalization.
- Encoder-Decoder Architecture.
